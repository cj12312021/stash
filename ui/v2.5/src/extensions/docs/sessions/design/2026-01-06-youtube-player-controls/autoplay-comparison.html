Autoplay Toggle Design Comparison

Comparing Form.Switch style vs YouTube-consistent icon button

Form.Switch Style Current

Pill track with sliding thumb icon. Based on Stash PR #6368 Form.Switch component.

ON
OFF

Analysis

  • Clear toggle metaphor (slides left/right)
  • Matches Stash Form.Switch component
  • Visually different from neighboring buttons
  • Wider footprint (48px vs 32px)
  • Not how YouTube does it

YouTube Icon Button Proposed

Standard circular button with color state. Matches CC, Settings, Fullscreen buttons exactly.

ON
OFF

Analysis

  • Identical size to neighboring buttons (32px)
  • Matches YouTube's actual implementation
  • Blue fill clearly indicates "on" state
  • Seamless visual integration
  • Less obvious toggle metaphor

Recommendation: YouTube Icon Button

The YouTube-consistent design provides better visual consistency with the control bar. The blue filled background when "on" is clear enough for state communication, and it matches exactly how YouTube handles their autoplay toggle. The Form.Switch design, while familiar from Stash's form components, looks out of place among circular icon buttons.

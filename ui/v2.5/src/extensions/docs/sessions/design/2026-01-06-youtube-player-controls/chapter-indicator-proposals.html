Enhanced Chapter Indicator

Three design proposals for replacing the SceneMarkersPanel with an integrated chapter indicator that supports full marker CRUD operations.

Recommended

Option A: Dropdown + Modal Form

Minimal disruption, familiar pattern

Keep the chapter indicator compact in the control bar. Add quick action buttons (edit/delete) on hover for each marker in the dropdown. Create/Edit operations open a modal dialog with the full marker form. This approach reuses the existing SceneMarkerForm component wrapped in a styled modal.

Recommendation: Option A (Modal Form)

Option A provides the best balance of functionality, implementation simplicity, and user familiarity. It reuses the existing SceneMarkerForm component, works well on all screen sizes, and follows established UX patterns for CRUD operations. The compact dropdown keeps the player interface clean while providing quick access to all marker management features. Options B and C can be considered for future enhancements if users request more visual marker management.

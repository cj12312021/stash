Responsive Strategy Recommended

Large >768px

  • All controls visible
  • Volume slider expands on hover
  • Thumbnail preview enabled
  • Chapter dropdown as-is

Medium 481-768px

  • Hide Next button
  • Move volume to settings menu
  • Keep time + chapter
  • Keep full right group

Small ≤480px

  • Play + Settings + Fullscreen only
  • Time/chapter on separate row above
  • 44px touch targets
  • Hide autoplay, CC (access via settings)
  • Disable hover thumbnail
/* Mobile-first responsive controls */ @media (max-width: 480px) { .control-btn { width: 44px; height: 44px; } .next-btn, .volume-control, .autoplay-btn, .cc-btn { display: none; } .controls-row { flex-wrap: wrap; } .time-chapter-row { width: 100%; order: -1; margin-bottom: 8px; } .hover-preview { display: none; } }

Desktop Overlay >480px

  • 280-320px floating panel
  • Positioned near settings button
  • Backdrop blur effect
  • Click outside to close

Mobile Modal ≤480px

  • Full-screen modal (100vw × 100vh)
  • Close button in header
  • 48px touch target rows
  • Larger toggle switches
  • Include hidden controls (Volume, Autoplay, CC)
  • Slide-in from bottom animation

Mobile Submenus

  • Full-screen slide from right
  • Large back button (← Quality)
  • Larger radio button targets
  • Slider tracks: 8px height (vs 4px)
  • Thumb size: 24px (vs 14px)

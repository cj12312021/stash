Autoplay Toggle — Integration Study

Designing a pill-track toggle that harmonizes with 32px icon buttons

Approach 1: Compact Inline Track

Full pill track with visible background. Thumb slides with icon inside. Track background changes color when active.

Width: 44px | Track: 32×14px | Thumb: 18px

Approach 2: Embedded Track Button

Smaller track where thumb extends beyond track bounds. Track fills with primary color when on. Compact footprint.

Width: 40px | Track: 28×12px | Thumb: 16px

Approach 3: Minimal Track Recommended

Icon-forward design. Ultra-thin 4px track acts as a "rail" while the prominent thumb carries the icon. Track glows when active. Bouncy spring animation on slide.

Width: 42px | Track: 32×4px | Thumb: 20px

Approach 4: Segmented Toggle

Two icons visible (pause/play), thumb slides between them. Both states always visible, selected state highlighted. More iOS-like toggle behavior.

Width: 48px | Height: 24px | Icons: 10px
